    Mesonet buildout across the Upper Missouri River Basin

    What this shows

    The Upper Missouri River Basin is divided into ACE grid cells, each sized to hold one Mesonet station. A cell is shaded by how far along its station is: operational, scheduled for a given install year, under construction, or still available. Orange dots mark the actual station locations. Cell assignments are provisional and change as siting work proceeds.

    How to use it

    • Search — press / to jump there; ↑/↓ + Enter to pick.
    • Legend — click a row to hide a status; double-click (or Shift+Enter) to isolate it.
    • Layers — chips toggle station dots and the county / watershed / tribal-land reference overlays.
    • Hover a cell for its status; click for station details and a dashboard link.
    • The tag button toggles grid cell labels.
    • Esc closes any open popup.

    Share or bookmark

    The URL reflects every choice — copy it from the address bar. ?cell=<id> deep-links a grid cell and ?station=<id> a station.

    Data

    Station status is read live from the Montana Climate Office station registry on every load. Grid geometry is packaged with this page; county, watershed, and tribal-land overlays stream from the MCO data service when you turn them on.
